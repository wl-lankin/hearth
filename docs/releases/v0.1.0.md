The first build of Hearth, a local PHP development environment for Windows and macOS.

This release is the foundation the next milestones build on:

- The Hearth app lives in the tray and starts with your computer (you can turn that off in Settings).
- A Dashboard shows that the Hearth core is running; Settings has the theme, startup options and updates.
- The `hearth status` command reports whether the core is running.
- Hearth updates itself from these GitHub releases.

PHP versions, `.test` sites, services and the rest arrive in the next releases.

The installers are not code-signed yet: Windows SmartScreen and macOS Gatekeeper will warn the first time you open them.
